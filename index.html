Google Sheets backup

  

  
  
  

    
    
  

  
  

    Recovery code
    
Only this phone can read the sheet. Save this code somewhere safe (e.g. a note or email to yourself); you need it to restore on a new phone.

    

    
    

  

  
  
To update: open your sheet → Extensions → Apps Script → select all → paste → 💾 Save → Deploy → Manage deployments → ✏️ → Version: New version → Deploy. The link stays the same; then tap Back up now.

  

    First-time set-up steps ▾
    
    
      
  1. In Chrome (Desktop site on), open sheets.new and name the sheet, e.g. “Vietnam trip backup”.
    2. 
      
  2. Extensions → Apps Script. Delete what’s there, tap Copy the script below, paste it in, and tap 💾 Save.
    3. 
      
  3. Deploy → New deployment → ⚙ Web app. Execute as: Me. Who has access: Anyone. Tap Deploy.
    4. 
      
  4. Allow access: Advanced → Go to project (unsafe) → Allow. It’s your own script, so this warning is expected.
    5. 
      
  5. Copy the Web app URL, paste it in the box above and tap Back up now.
    6. 
    

    
    

  

  
The sheet includes your personal spending, so don’t share it. “Anyone” only lets this phone in: the first phone that connects locks the sheet to itself.

  
Backup

  

  

    
    
  

  

    
    
  

  

  
Save backup puts a file in your phone’s Downloads. Send backup lets you pick WhatsApp, Gmail or Drive, so a copy lives off the phone too. Backups never include your API key.

  
  

  

  
You’re opening this as a file, not the installed app. It won’t work as an offline app this way, and records saved here stay with this file only.
